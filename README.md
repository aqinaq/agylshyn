# agylshyn

Cambridge-тің он оқулығының жаттығулары — браузерде істейтін, серверсіз
жаттығу сайты. Сұрақтар PDF-тен шығарылып JSON-ға жиналған, жауап бірден
тексеріледі, прогресс `localStorage`-та сақталады.

## Кітаптар

| Кітап | Деңгей | Сұрақ |
|---|---|---|
| Essential Grammar in Use | A1–A2 | 1 984 |
| English Grammar in Use | B1–B2 | 3 948 |
| Advanced Grammar in Use | C1–C2 | 2 473 |
| Vocabulary in Use — Elementary | A1–A2 | 1 024 |
| Vocabulary in Use — Pre-Intermediate | A2–B1 | 2 390 |
| Vocabulary in Use — Upper-Intermediate | B2 | 2 616 |
| Vocabulary in Use — Advanced | C1–C2 | 2 451 |
| Collocations in Use — Intermediate | B1–B2 | 1 319 |
| Academic Vocabulary in Use | B2–C1 | 1 321 |
| Business Vocabulary in Use — Intermediate | B1–B2 | 1 076 |
| Cambridge IELTS 19 — Academic | B2–C1 | 320 |
| Cambridge IELTS 20 — Academic | B2–C1 | 320 |
| Cambridge IELTS 21 — Academic | B2–C1 | 320 |

IELTS кітаптары юниттерге емес, тесттерге бөлінеді: әр кітапта 4 тест, әр
тесттің Listening және Reading бөлімі бөлек юнит — барлығы 8 юнит, 320 сұрақ.
Үшеуін де `site/tools/build_ielts.py` құрастырады.

Үшеуі жауап парағы ретінде жұмыс істейді: сұрақтардың өзі кітапта қалады
(PDF панелі әдепкіден ашық), сайтта тек нөмірленген жауап өрістері тұрады.
Кітап бере алмайтын нәрселер ғана қосылған — әр Listening бөлімінің аудиосы
және (20, 21-де) әр Reading мәтіні, әрқайсысы өз сұрақтарының дәл алдында.

**19-шы басқаша жиналған.** Оның PDF-і — Cambridge-тің ресми үзіндісі толық
кітаптың сканына жалғанған нәрсе: сұрақ беттері де, жауап кілті де сурет,
ешбір парсер оқи алмайды. Бірақ жауап парағына кілт қана керек, ал кілт беттері
көзбен анық оқылады — сондықтан 320 жауап `site/tools/ielts-19-key.json`
файлына қолмен теріліп жазылған. Қате тапсаң, сол файлды түзеп, билдті қайта
жүргіз.

Аудиті бүлінген Mindset 1/2/3 қосылмады. Collins Reading / Listening екеуі
бір кезде қосылып, кейін мүлдем алынып тасталды: OCR-дан шыққан деректері
дұрыс болмады.

Барлығы 937 юнит, 21 562 есептелетін сұрақ (essential-grammar-дің 424 «елес» жолы алынып,
vocab-upint нағыз Upper-Intermediate мазмұнына ауыстырылды — төмендегі
«Аудиттен кейінгі жөндеу» бөлімін қара). Екеуін қосып тұрған сан, сондықтан
басты бетте бөлек те көрсетіледі:

| | Кітап | Юнит / бөлім | Сұрақ |
|---|---:|---:|---:|
| Оқулық (grammar + vocab) | 10 | 913 | 20 602 |
| IELTS | 3 | 24 | 960 |

Бөлу маңызды, өйткені IELTS-тің «юниті» — қырық сұрақтан тұратын тест бөлімі,
ал оқулықтың юниті — екі беттік тақырып. Қосылған 937 сан екі түрлі нәрсені
бір-біріне үйіп тұр. Басты беттегі жол `kind` бойынша бөледі (кітап тізімі
бойынша емес), әрі әрқайсысында қанша жауап бергенің де жазулы.

## Қалталар

```
site/              біріктірілген сайт — негізгі нұсқа осы (site/README.md)
site/tests/        тесттер: node site/tests/run.js (site/tests/README.md)
content/           ақылы кітаптардың JSON-ы. Репозиторийде де, деплойда да жоқ
                   (.gitignore); билдтен кейін upload_content.py Supabase-ке
                   итереді, оқушыға сол жерден барады
AUDIT.md           мазмұн дұрыстығы мен функционалдық аудиті

vocab-srs/         сөз карталарының түпнұсқа прототипі (React + Express).
                   Сайтқа кіретін нұсқасы — site/srs.js, серверсіз әрі
                   тәуелсіз; бұл қалта тарих үшін тұр, деплойға кірмейді
                   (node_modules .gitignore-да)

ayaulyayalama/     Essential Grammar in Use    ┐
enginuse/          English Grammar in Use      │ бастапқы жеке қосымшалар.
advancedinuse/     Advanced Grammar in Use     │ site/ солардың деректерінен
vocab-preint/      Vocabulary Pre-Intermediate │ жиналады, өздері өзгертілмейді
vocab-upint/       Vocabulary Upper-Int        │
vocab-adv/         Vocabulary Advanced         ┘
```

Бұл алтауынан `build_data.py`-ға керегі — тек `exercises.json`. Бесеуінде
оқулықтың PDF-і де жатқан, бірақ ол `site/pdf/`-тегімен байтпен бірдей
көшірме болатын, сондықтан алынып тасталды (билд PDF-ті әрқашан `site/pdf/`-тен
оқиды). Жалғыз ерекшелік — `ayaulyayalama/`-дағы 71 МБ түпнұсқа скан: ол
`site/pdf/essential-grammar.pdf`-тен (15.5 МБ) басқа әрі сапалырақ файл,
кейінге қалдырылған OCR жұмысына керек болғандықтан қалды.

Кейін қосылған төрт кітаптың бастапқы қалтасы жоқ — олар `site/pdf/`-тегі
PDF-тен тікелей оқылады:

```
site/tools/build_vocab_elem.py    → tools/vocab_elem_exercises.json
site/tools/build_collocations.py  → tools/collocations_exercises.json
site/tools/build_academic.py      → tools/academic_exercises.json
site/tools/build_business.py      → tools/business_exercises.json
site/tools/keyparse.py            соңғы үшеуіне ортақ кілт талдағышы
```

`build_data.py` сол төрт файлды оқып, қалған алтауымен бірге жинайды. PDF жолын
`BOOK_PDF` айнымалысымен ауыстыруға болады.

## Іске қосу

`fetch()` қолданылатындықтан файлды қос шертіп ашуға болмайды — сервер керек:

```
cd site && python3 -m http.server 8777
# http://localhost:8777
```

Деректерді бастапқы қалталардан қайта жинау:

```
python3 site/tools/build_data.py      # 10 grammar/vocabulary кітабы
python3 site/tools/build_ielts.py     # Cambridge IELTS 19/20/21
```

Екеуі де `data/index.json`-ды **біріктіріп** жаңартады (`tools/index_json.py`),
сондықтан біреуін жеке жүргізу қалғандарының жолдарын өшірмейді. Индекс
бұзылып қалса, дискідегі деректен қайта құруға болады:

```
python3 site/tools/index_json.py      # 13 кітап · 937 юнит · 21 562 сұрақ
```

Индекстегі сан — прогреске **есептелетін** сұрақ: кітаптың өзі шешіп берген
үлгі жолдар (worked examples) мен тексерілмейтін тапсырмалар (эссе, кроссворд)
кірмейді. `index_json.py`-дегі `tracked()` пен app.js-тегі `isTracked()` бір
ережені ұстайды, сондықтан карточкадағы «істелді / барлығы» юниттің ішіндегі
жолақпен бір нәрсені білдіреді. Билд жаттығуларды жөндеген сайын бұл сан
жылжиды — жоғарыдағы кестені сол шығысқа қарап жаңарту керек.

Тексеру:

```
node site/tests/run.js
```

Серверді өзі көтереді, headless Chrome-ды қосады, он бес жиынтықты жүргізеді
(деректің тұтастығы, жауап салыстырғышы, қосымшаның өзі, телефон мен диалогтар,
админ бөлімі, ақылы қабат, емтихан режимі, Writing/Speaking, диктант, қателер,
тегін үлгілер, сыныптар, қазақша түсіндірмелер, прогресті сақтау ескертуі,
аудио мен PDF қайдан алынатыны), сосын бәрін жабады. Толығырақ — [site/tests/README.md](site/tests/README.md).

Бұл команда енді әр push пен pull request сайын GitHub Actions-та жүреді
(`.github/workflows/tests.yml`), ал деплой оның браузерсіз жартысын —
`audit.js` пен `match_test.js` — жарияламас бұрын өзі жүргізеді. Бұрын тесттер
біреу есіне түсіргенде ғана жүретін; енді бүлінген билд қызыл болады.

### Аудио мен PDF: объект-қойма (`site/media.config.js`)

Екі қалта бүкіл жобаның көлемін жасайды: `site/audio/` (57 трек, ~340 МБ) және
`site/pdf/` (13 кітап, ~209 МБ). Екеуі де репозиторийде жатқанда клон 700 МБ
болатын — біржола, әр көшірмеде, мәңгі: git екілік файлды тұтас әрі әрқашан
сақтайды, ал бұл файлдар ешқашан өзгермейді.

Сондықтан олар қоймаға көшірілді. Дерек файлдарының ішіндегі жолдар өзгерген
жоқ — әлі де `audio/c20/t1p1.m4a`, `pdf/ielts-21.pdf` — тек алдына база
қосылады, әрі ол бір ғана жерде істейді: `audioUrl()` мен `pdfUrl()`
(`app.js`). Бос база — «сайттың қасында», яғни қалталары әлі тұрған жергілікті
клон үшін дұрыс әдепкі.

```
python3 site/tools/upload_media.py            # екі қалтаны да жүктеу
python3 site/tools/upload_media.py --check    # бәрі орнында ма, әрі АШЫҚ па
python3 site/tools/upload_media.py --plan     # не кетеді, қанша МБ
```

Кілттер `.env`-те (gitignore-да): `R2_ACCOUNT_ID` (немесе `R2_ENDPOINT`),
`R2_BUCKET`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`. Құрал S3 API-мен
сөйлеседі — R2, B2, S3 үшеуі де жарайды; boto3 керек емес.

`--check` екі бөлек сұрақ қояды, өйткені олар шынымен екі бөлек сұрақ: файл
қоймада бар ма (қолтаңбаланған сұраныспен) және оқушының браузері оны ала ала
ма (`media.config.js`-тегі URL арқылы, кілтсіз). Жабық қойма бірінші сұраққа
мінсіз жауап беріп, екіншісінде 401 қайтарады — бұл көшірудің ең ықтимал қате
жолы.

**Қоймадан не талап етіледі.** `AUDIO_BASE` үшін екеу: ашық оқу және Range
(`Accept-Ranges: bytes`) — Range болмаса трек ойнайды, бірақ ішінде алға-артқа
жылжу істемейді. `PDF_BASE` үшін бұл екеуі **әрі CORS**: PDF-ті браузер сеніп
жүктейтін тег емес, `pdf.js` өзі оқиды, ал service worker жауабын кэштеп,
кітапты офлайн ашылатын қылады — екеуі де cross-origin оқу. Керекті
тақырыптар `site/media.config.js`-тің басында жазулы; `Expose-Headers` де
бірінші жол сияқты маңызды.

Файл табылмаса, ойнатқыштың орнына «Аудио қолжетімсіз» деген жазу шығады —
үнсіз өлі батырма қалмайды.

### Тарихтан алып тастау (бір рет)

Файлдарды қоймаға көшіру клонды кішірейтпейді: git тарихы оларды әлі ұстап
тұр. Ол үшін тарихты қайта жазу керек, ал ол — **қайтымсыз**: барлық commit
SHA өзгереді, әркімнің клоны мен форкі бұзылады, `--force` push керек.
Сондықтан бұл қадам қоймадағы файлдар жұмыс істеп тұрғаны тексерілгеннен кейін
ғана жасалады.

Реті:

```bash
# 1. Файлдар қоймада әрі ашық екеніне көз жеткіз
python3 site/tools/upload_media.py --check
# 2. media.config.js-ке базаларды жаз, сайтты ашып тексер (аудио, PDF, телефон)
# 3. Қалталарды жұмыс ағашынан алып, .gitignore-ға қос
git rm -r --cached site/audio site/pdf
printf 'site/audio/\nsite/pdf/\n' >> .gitignore
git commit -am "Аудио мен PDF қоймаға көшті"
# 4. Тарихтан тазала (pipx install git-filter-repo)
git filter-repo --invert-paths --path site/audio --path site/pdf
# 5. filter-repo remote-ты өшіреді — қайта қос та, күшпен итер
git remote add origin https://github.com/aqinaq/agylshyn.git
git push --force origin main
```

Тарихтағы көлем: `site/audio` — 547 МБ (дискідегі 340 МБ емес: ескі, ауыстырылған
нұсқалары да сонда), `site/pdf` — 217 МБ. Барлығы 708 МБ-тың ~764 МБ-ы емес,
дәл осы екеуі ~625 МБ-тың басым бөлігі; қалғаны — код, дерек және
`ayaulyayalama/`-дағы 71 МБ скан.

**Сол сканды не істеу керек?** Ол — жоғарыдағы «Қалталар» бөлімінде жазылған,
әдейі қалдырылған файл: `site/pdf/essential-grammar.pdf`-тен (15.5 МБ) сапалы,
кейінге қалдырылған OCR жұмысына керек. Оны да алып тастасаң тарихтан тағы
71 МБ кетеді, бірақ сонымен бірге сол жұмыстың бастапқы материалы да кетеді.
Шешім — сенікі; егер алып тастайтын болсаң, сол бір `filter-repo` шақыруына
қосып жібер, екінші рет тарих қайта жазылмасын:

```bash
git filter-repo --invert-paths --path site/audio --path site/pdf \
  --path 'ayaulyayalama/Essential Grammar in Use 2nd [languagedownload.ir].pdf'
```

## Тегін бөлігі және жазылым

Алты кітап толығымен тегін — `essential-grammar`, `grammar`, `vocab-elem`,
`vocab-preint`, `collocations` және `ielts-19`. Олар аккаунтсыз да, интернетсіз
де жұмыс істейді. Алғашқы бесеуі A1-ден B1-ге дейін жеткізеді; `ielts-19` —
үлгі: емтихан сөресін сатып алу-алмауды шешкен адам бір толық тестті басынан
аяғына дейін істеп көруі керек. Қалған жетеуі (C1–C2 сөресі мен қалған екі
IELTS) жазылыммен ашылады: **айлық 2000 ₸**, **мәңгілік 5000 ₸**.

Ақылы кітаптардың алғашқы 1–2 юниті тегін үлгі ретінде ашық: құлып емес,
нағыз жаттығулар ашылады, бетінде «101 юниттің 2-і ашық» деген жолақ пен ашу
түймесі тұрады. Қанша беру `site/tools/tiers.json` ішіндегі `sample` блогында
жазылады, файлдарын `site/tools/build_samples.py` кесіп шығарады.

Үлгіге кітаптың басы алынады, бірақ юнит сұрағын өзі көрсете алатын болуы
керек: жолдарының кемі жартысы өз мәтінімен тұруы шарт. Сондықтан Business
Vocabulary in Use-тің үлгісі 2 және 4-юнит — оның 1-юниті он тоғыз жолдың
он сегізінде «кітаптан қара» деп тұрады, яғни сатылатын нәрсенің қарама-қарсысын
көрсететін еді. Әр юниті әдейі жауап парағы болатын кітап (IELTS) бұл ережеден
тыс: онда таңдайтын ештеңе жоқ, алғашқы бөлімдері сол күйі беріледі.

Оқулық PDF-і мен Listening аудиосы — он үш кітаптың бәрінде ашық. Ақылысы —
жаттығулары: тексерілетін жауап, қателер беті, статистика, сессия.

```
site/data/<id>.json        тегін кітаптардың жаттығулары → офлайн кэштеледі
site/data/sample/<id>.json ақылы кітаптардың тегін үлгісі (әдейі жарияланған)
site/data/notes/<id>.json  қазақша түсіндірмелер
content/<id>.json       ақылы кітаптар (репозиторийден тыс, .gitignore-да)
Supabase book_content   оқушыға жететін жалғыз көшірме, RLS-пен қорғалған
site/pdf/<id>.pdf       оқулықтар — бәрі ашық
site/audio/…            Listening аудиосы — бәрі ашық
```

Құлыпты браузер емес, Postgres шешеді: `book_content` кестесінің select
саясаты `has_access()`-ке сүйенеді, ол `subscriptions` кестесіне қарап,
мерзімді сервердің сағатымен өлшейді. Ақылы кітаптың файлы сайтта мүлде жоқ,
сондықтан devtools-тағы кез келген өзгеріс құлыптың суретін ғана береді.

## Мүмкіндіктері

- **IELTS: емтихан режимі және band**. Тест бөлімін уақытпен тапсырасың
  (Listening 40 мин, Reading 60 мин): жауап бірден тексерілмейді, соңында
  бәрі бір-ақ рет тексеріліп, ұпай мен шамамен band шығады, бөлім-бөлім
  талданады. Аяқталған жүгірулер сақталады да, статистикада «соңғысы / ең
  жақсысы» болып тұрады. Cambridge 21-де кітаптың өз бағасы да көрсетіледі
  («If you score …» кестесі PDF-тен оқылған). Band — шамамен есеп: бұл
  кітаптарда Cambridge ресми кесте бермейді, әр жерде солай деп жазулы
- **IELTS: Writing және Speaking** (`#/b/<id>/tasks/<тест>`). Юниттер тізімі
  L1 R1 W1 S1 болып тұрады — бір тесттің төрт бөлімі қатар, әрқайсысы өз беті.
  Емтихандағы уақыт (20/40 мин), сөз санағышы (≥150/250), өзі сақталатын
  жобаң; Speaking-те cue-card таймері (1 мин дайындық, 2 мин сөйлеу) және
  дауысыңды жазып тыңдау. Writing-ті емтихан режимімен де тапсыруға болады:
  екі тапсырмаға бір сағат, жаттығу құралдары жабылады. Баға қойылмайды —
  эссені машина тексере алмайды, тексеруші нені бағалайтыны ғана жазылып
  тұрады. Тапсырманың өз мәтіні (кесте, сурет, cue-card) кітапта қалады
- **Диктант және аудио мәтіні**. Cambridge 21-дің audioscript-і PDF-тен
  шығарылған: жазбаны оқи да аласың, әр үшінші сөзі жасырылған диктант та
  істей аласың. Ойнатқышта ↺5 секунд пен 0.75× бар. Емтихан режимінде мәтін
  де, баяулату да жоқ
- **Қазақша түсіндірме**. Кітап ағылшынша түсіндіреді, ал артикль, present
  perfect, phrasal verb сияқты тұстар қазақ тілді оқушыға дәл сол себептен
  қиын. Сондай юниттерде жаттығулардың үстінде қазақша қысқа түсіндірме
  тұрады (`site/data/notes/<кітап>.json`), қате жауаптың жанында да сілтемесі
  шығады
- **Сынып (`#/class`, басты беттегі «Сынып» карточкасы)**: сынып ашасың,
  6 таңбалы кодты оқушыларға бересің,
  олар қосылған соң кім қанша істегенін көресің. Мұғалім тек санақты көреді —
  қанша жауап, қаншасы дұрыс, соңғы рет қашан кірген; жазған жауаптарын
  ешқашан көрмейді, ондай функция схемада жоқ
- Жауапты бірден тексеру, қателер беті, streak / mastered статистикасы
- **«Осында жаз»**: машина тексере алмайтын жаттығуда да (эссе, кроссворд,
  сканнан сұрағы шықпаған жол, тіпті жаттығуы жоқ юнит) жазатын орын тұрады —
  өздігінен сақталады, сөз саны көрсетіледі, аккаунтпен бірге бұлтқа кетеді.
  «Жауапты көрсету» жалғыз тұрса, ол — қате: сайттың бар мәні дәптерге емес,
  бетте жазу
- **«Қайдан бастаймын?»**: 8 сұрақтық қысқа тест деңгейді бағалап, содан
  бастайтын екі кітапты ұсынады (тіркелусіз, әр жолы жаңа сұрақтармен).
  Ұсынылған кітап ақылы болса не сұрақтары тек PDF-те болса, сол жерде
  жазулы тұрады
- **Жаттығу сессиясы** (`⚡`): бір экранда бір сұрақ — қателер, қайталау
  мерзімі жеткендер және жаңалары араласып келеді. Бір кітаптан не бәрінен
  бірдей; соңында нәтиже мен қате жауаптардың тізімі
- **Көмек (💡)**: жауаптың пішіні → бірінші әріптер → жауаптың өзі. Көмекпен
  берілген жауап меңгерілгенге жатпайды, сұрақ ертең қайта келеді
- **Тыңдау (🔊)**: сұрақты, дұрыс жауапты, сөздіктегі сөзді браузердің өз
  даусы оқиды (қосымша файл да, интернет те қажет емес)
- **Іздеу (Ctrl+K)**: сұрақтың мәтіні, жауабы, юнит атауы бойынша — бір
  кітаптан немесе бәрінен; нәтиже дәл сол сұраққа апарады
- Сөздік: сөзді меңзе (немесе қос шерт, ұзақ бас) — қазақша аудармасы шығады.
  1 385 сөздік ядро офлайн істейді, қалғаны API арқылы табылып кэштеледі
- **Сөз карталары (`🗂`)**: аудармасы шыққан терезедегі ＋ сол сөзді жеке
  жинағыңа қосады. Екі рет қате жауап берілген сұрақ та өздігінен картаға
  айналады (бетінде — сұрақ, артында — жауап); қателер бетінде «бәрін қосу»
  түймесі бар, ал автоматты режимді жинақтың баптауынан өшіруге болады. Күн сайын аралық қайталау (SM-2): білсең — сирейді,
  ұмытсаң — жиілейді. Әр түйменің үстінде «келесі рет қашан» жазулы тұрады,
  сырғытып та бағалауға болады. Тізімнен (CSV/TSV) импорт, файлға сақтық
  көшірме — бәрі браузерде, серверсіз
- Оқулық PDF-і сол беттің ішінде, керекті бетінен ашылады
- Интерфейс екі тілде: қазақша / ағылшынша
- Тақырыбы екеу: ашық / қараңғы
- Прогресс уақыт белгісімен жазылады: «бүгін», күнделікті серия (streak),
  соңғы 30 күн графигі, бөлім бойынша әлсіз тұстар, қайталау кестесі
- Дәлдік пен қамту бөлек көрсетіледі; прогресті JSON-ға сақтап/қайтаруға болады
- **Аккаунт (қосымша)**: Google, поштаға келетін сілтеме немесе пароль арқылы
  кіресің де, прогресс бұлтқа сақталып, басқа құрылғыда жалғасады. Міндетті
  емес — баптау бос болса, түйме де көрінбейді, бәрі бұрынғыдай тек осы
  браузерде сақталады. Баптау: [site/README.md](site/README.md#аккаунт-және-бұлт-синхы-қосымша)
- **Қолданушылар тізімі (`#/users`)**: кім тіркелген, қашан кірген, қанша
  кітап пен жауап — сұрыпталатын кесте. Тек админге: админ болу деген
  `public.admins` кестесіндегі жол, ол кестеде жазу саясаты жоқ, сондықтан
  оны SQL Editor-ден ғана қосуға болады. Тізімнің өзін серверде `is_admin()`-ды
  қайта тексеретін функция қайтарады, яғни браузерде флагты «қосып қою» ештеңе
  бермейді. Тізімде санақ қана — басқа адамның жауаптары ешқашан ашылмайды
- Офлайн істейді (PWA — Service Worker кэштейді)

Толық құжаттама — [site/README.md](site/README.md).

## Аудиттен кейінгі жөндеу

Аудитте табылған мәселелер бойынша жасалғаны ([AUDIT.md](AUDIT.md) §8 реті):

- **vocab-upint** енді нағыз Upper-Intermediate мазмұны (101 юнит, 2 616 сұрақ,
  өз PDF кілтімен 100 %). Бұрын Pre-Intermediate көшірмесі болатын.
- **essential-grammar**-дің 424 «елес» жолы (сұрағы да, жауабы да жоқ) алынды —
  статистика енді шынайы (1 984 нақты сұрақ).
- **grammar**-дің юнит атаулары мен бөлімдері PDF-тің Contents бетінен қайта
  оқылды (36 қате атау түзелді); grammar мен vocab-upint-ке `section` қосылды.
- **Жауап тексеру:** үтірлі тізімдер енді ретсіз салыстырылады
  (729 сұрақ 0 % → 100 %); беттің «Key to Exercises» іздері жауаптан кесілді.
- **Прогресс сенімді:** жауап бет жабылғанда бірден жазылады
  (`visibilitychange`/`pagehide`), екі қойынды бір-бірін өшірмейді
  (`storage` оқиғасында біріктіру), әр жазбада уақыт белгісі (`ts`) бар.
- **Статистика:** Дәлдік / Қамту / Меңгерілді / Бүгін карточкалары, 30 күндік
  график, бөлім бойынша жинақ, сұрыпталатын кесте, «қайталауға дайын» тізім.
- **Кітапаралық көрініс:** басты бетте жалпы дәлдік, «бүгін», «осы аптада»,
  барлық кітаптағы қате саны + 30 күндік график; әр кітап карточкасында
  қайталауды күтетін қате саны.
- **Қателер беті:** жауап жаңа әрекетке дейін жасырылады, ескі қате өріске
  толмайды («өткен жолы: …» болып бөлек), нұсқаулық әр жаттығуда бір рет.
- **Қолжетімділік:** кіріс өрістерінде `aria-label`, нәтижеде `aria-live`,
  кестеде пернетақта, белсенді таб/юнитте `aria-current`, модальда фокус қақпаны.
- **Мобиль:** табтар астыңғы жолаққа шықты — жоғарғы жолақ бір қатар, кітап
  атауы қиылмайды. Үш «Vocabulary in Use» деңгеймен ажыратылды.
- **Экспорт/импорт**, **офлайн (PWA)** қосылды.
- **Кейінге қалдырылды:** мәтіндегі OCR бос орындарын (`de grees`) автоматты
  жөндеу — сөздіксіз қауіпсіз істелмейді (дұрыс мәтінді бүлдіру қаупі);
  салыстыруға әсер етпейді. Авторлық құқық (Т6) — PDF-терді жариялау шешімі
  иесінде.
