# agylshyn

Cambridge-тің он оқулығының жаттығулары — браузерде істейтін, серверсіз
жаттығу сайты. Сұрақтар PDF-тен шығарылып JSON-ға жиналған, жауап бірден
тексеріледі, прогресс `localStorage`-та сақталады.

IELTS кітаптары юниттерге емес, тесттерге бөлінеді: әр кітапта 4 тест, әр
тесттің Listening және Reading бөлімі бөлек юнит — барлығы 8 юнит, 320 сұрақ.
Үшеуін де `site/tools/build_ielts.py` құрастырады.

Үшеуі жауап парағы ретінде жұмыс істейді: сұрақтардың өзі кітапта қалады
(PDF панелі әдепкіден ашық), сайтта тек нөмірленген жауап өрістері тұрады.
Кітап бере алмайтын нәрселер ғана қосылған — әр Listening бөлімінің аудиосы
және (20, 21-де) әр Reading мәтіні, әрқайсысы өз сұрақтарының дәл алдында.

**19-шы басқаша жиналған.** Оның PDF-і — Cambridge-тің ресми үзіндісі толық
кітаптың сканына жалғанған нәрсе: сұрақ беттері де, жауап кілті де сурет,
ешбір парсер оқи алмайды. Бірақ жауап парағына кілт қана керек, ал кілт беттері
көзбен анық оқылады — сондықтан 320 жауап `site/tools/ielts-19-key.json`
файлына қолмен теріліп жазылған. Қате тапсаң, сол файлды түзеп, билдті қайта
жүргіз.

Collins екеуінде * — тек таза жауаптар автотексеріледі; қалған жаттығулардың
ресми кілті «жауапты көрсету» батырмасымен ашылады (OCR қатесі көрінеді, оқушы өзі салыстырады). Аудиті бүлінген Mindset 1/2/3 қосылмады.

Барлығы шамамен 21 973 автотексерілетін сұрақ (essential-grammar-дің 424 «елес» жолы алынып,
vocab-upint нағыз Upper-Intermediate мазмұнына ауыстырылды — төмендегі
«Аудиттен кейінгі жөндеу» бөлімін қара).

## Қалталар

```
site/              біріктірілген сайт — негізгі нұсқа осы (site/README.md)
AUDIT.md           мазмұн дұрыстығы мен функционалдық аудиті

ayaulyayalama/     Essential Grammar in Use    ┐
enginuse/          English Grammar in Use      │ бастапқы жеке қосымшалар.
advancedinuse/     Advanced Grammar in Use     │ site/ солардың деректерінен
vocab-preint/      Vocabulary Pre-Intermediate │ жиналады, өздері өзгертілмейді
vocab-upint/       Vocabulary Upper-Int        │
vocab-adv/         Vocabulary Advanced         ┘
```

Кейін қосылған төрт кітаптың бастапқы қалтасы жоқ — олар `site/pdf/`-тегі
PDF-тен тікелей оқылады:

```
site/tools/build_vocab_elem.py    → tools/vocab_elem_exercises.json
site/tools/build_collocations.py  → tools/collocations_exercises.json
site/tools/build_academic.py      → tools/academic_exercises.json
site/tools/build_business.py      → tools/business_exercises.json
site/tools/keyparse.py            соңғы үшеуіне ортақ кілт талдағышы
```

`build_data.py` сол төрт файлды оқып, қалған алтауымен бірге жинайды. PDF жолын
`BOOK_PDF` айнымалысымен ауыстыруға болады.

## Іске қосу

`fetch()` қолданылатындықтан файлды қос шертіп ашуға болмайды — сервер керек:

```
cd site && python3 -m http.server 8777
# http://localhost:8777
```

Деректерді бастапқы қалталардан қайта жинау:

```
python3 site/tools/build_data.py
```

## Мүмкіндіктері

- Жауапты бірден тексеру, қателер беті, streak / mastered статистикасы
- **Жаттығу сессиясы** (`⚡`): бір экранда бір сұрақ — қателер, қайталау
  мерзімі жеткендер және жаңалары араласып келеді. Бір кітаптан не бәрінен
  бірдей; соңында нәтиже мен қате жауаптардың тізімі
- **Көмек (💡)**: жауаптың пішіні → бірінші әріптер → жауаптың өзі. Көмекпен
  берілген жауап меңгерілгенге жатпайды, сұрақ ертең қайта келеді
- **Тыңдау (🔊)**: сұрақты, дұрыс жауапты, сөздіктегі сөзді браузердің өз
  даусы оқиды (қосымша файл да, интернет те қажет емес)
- **Іздеу (Ctrl+K)**: сұрақтың мәтіні, жауабы, юнит атауы бойынша — бір
  кітаптан немесе бәрінен; нәтиже дәл сол сұраққа апарады
- Сөздік: сөзді меңзе (немесе қос шерт, ұзақ бас) — қазақша аудармасы шығады.
  1 385 сөздік ядро офлайн істейді, қалғаны API арқылы табылып кэштеледі
- Оқулық PDF-і сол беттің ішінде, керекті бетінен ашылады
- Интерфейс екі тілде: қазақша / ағылшынша
- Тақырыбы екеу: ашық / қараңғы
- Прогресс уақыт белгісімен жазылады: «бүгін», күнделікті серия (streak),
  соңғы 30 күн графигі, бөлім бойынша әлсіз тұстар, қайталау кестесі
- Дәлдік пен қамту бөлек көрсетіледі; прогресті JSON-ға сақтап/қайтаруға болады
- Офлайн істейді (PWA — Service Worker кэштейді)

Толық құжаттама — [site/README.md](site/README.md).

## Мазмұн сапасы

[AUDIT.md](AUDIT.md) — әр жауап оқулықтың өз «Key to Exercises» бөлімімен

## Аудиттен кейінгі жөндеу

Аудитте табылған мәселелер бойынша жасалғаны ([AUDIT.md](AUDIT.md) §8 реті):

- **vocab-upint** енді нағыз Upper-Intermediate мазмұны (101 юнит, 2 626 сұрақ,
  өз PDF кілтімен 100 %). Бұрын Pre-Intermediate көшірмесі болатын.
- **essential-grammar**-дің 424 «елес» жолы (сұрағы да, жауабы да жоқ) алынды —
  статистика енді шынайы (1 984 нақты сұрақ).
- **grammar**-дің юнит атаулары мен бөлімдері PDF-тің Contents бетінен қайта
  оқылды (36 қате атау түзелді); grammar мен vocab-upint-ке `section` қосылды.
- **Жауап тексеру:** үтірлі тізімдер енді ретсіз салыстырылады
  (729 сұрақ 0 % → 100 %); беттің «Key to Exercises» іздері жауаптан кесілді.
- **Прогресс сенімді:** жауап бет жабылғанда бірден жазылады
  (`visibilitychange`/`pagehide`), екі қойынды бір-бірін өшірмейді
  (`storage` оқиғасында біріктіру), әр жазбада уақыт белгісі (`ts`) бар.
- **Статистика:** Дәлдік / Қамту / Меңгерілді / Бүгін карточкалары, 30 күндік
  график, бөлім бойынша жинақ, сұрыпталатын кесте, «қайталауға дайын» тізім.
- **Кітапаралық көрініс:** басты бетте жалпы дәлдік, «бүгін», «осы аптада»,
  барлық кітаптағы қате саны + 30 күндік график; әр кітап карточкасында
  қайталауды күтетін қате саны.
- **Қателер беті:** жауап жаңа әрекетке дейін жасырылады, ескі қате өріске
  толмайды («өткен жолы: …» болып бөлек), нұсқаулық әр жаттығуда бір рет.
- **Қолжетімділік:** кіріс өрістерінде `aria-label`, нәтижеде `aria-live`,
  кестеде пернетақта, белсенді таб/юнитте `aria-current`, модальда фокус қақпаны.
- **Мобиль:** табтар астыңғы жолаққа шықты — жоғарғы жолақ бір қатар, кітап
  атауы қиылмайды. Үш «Vocabulary in Use» деңгеймен ажыратылды.
- **Экспорт/импорт**, **офлайн (PWA)** қосылды.
- **Кейінге қалдырылды:** мәтіндегі OCR бос орындарын (`de grees`) автоматты
  жөндеу — сөздіксіз қауіпсіз істелмейді (дұрыс мәтінді бүлдіру қаупі);
  салыстыруға әсер етпейді. Авторлық құқық (Т6) — PDF-терді жариялау шешімі
  иесінде.
