# agylshyn

Cambridge-тің он оқулығының жаттығулары — браузерде істейтін, серверсіз
жаттығу сайты. Сұрақтар PDF-тен шығарылып JSON-ға жиналған, жауап бірден
тексеріледі, прогресс `localStorage`-та сақталады.

## Кітаптар

| Кітап | Деңгей | Сұрақ |
|---|---|---|
| Essential Grammar in Use | A1–A2 | 1 984 |
| English Grammar in Use | B1–B2 | 4 214 |
| Advanced Grammar in Use | C1–C2 | 2 465 |
| Vocabulary in Use — Elementary | A1–A2 | 1 024 |
| Vocabulary in Use — Pre-Intermediate | A2–B1 | 2 389 |
| Vocabulary in Use — Upper-Intermediate | B2 | 2 626 |

| Collocations in Use — Intermediate | B1–B2 | 1 312 |
| Academic Vocabulary in Use | B2–C1 | 1 316 |

| Cambridge IELTS 21 — Academic | B2–C1 | 320 |

IELTS кітаптары юниттерге емес, тесттерге бөлінеді: әр кітапта 4 тест, әр
тесттің Listening және Reading бөлімі бөлек юнит — барлығы 8 юнит, 320 сұрақ.
Үшеуін де `site/tools/build_ielts.py` құрастырады.

Үшеуі жауап парағы ретінде жұмыс істейді: сұрақтардың өзі кітапта қалады
(PDF панелі әдепкіден ашық), сайтта тек нөмірленген жауап өрістері тұрады.
Кітап бере алмайтын нәрселер ғана қосылған — әр Listening бөлімінің аудиосы
және (20, 21-де) әр Reading мәтіні, әрқайсысы өз сұрақтарының дәл алдында.

**19-шы басқаша жиналған.** Оның PDF-і — Cambridge-тің ресми үзіндісі толық
кітаптың сканына жалғанған нәрсе: сұрақ беттері де, жауап кілті де сурет,
ешбір парсер оқи алмайды. Бірақ жауап парағына кілт қана керек, ал кілт беттері
көзбен анық оқылады — сондықтан 320 жауап `site/tools/ielts-19-key.json`
файлына қолмен теріліп жазылған. Қате тапсаң, сол файлды түзеп, билдті қайта
жүргіз.

Аудиті бүлінген Mindset 1/2/3 қосылмады. Collins Reading / Listening екеуі
бір кезде қосылып, кейін мүлдем алынып тасталды: OCR-дан шыққан деректері
дұрыс болмады.

Барлығы 937 юнит, 21 672 есептелетін сұрақ (essential-grammar-дің 424 «елес» жолы алынып,
vocab-upint нағыз Upper-Intermediate мазмұнына ауыстырылды — төмендегі
«Аудиттен кейінгі жөндеу» бөлімін қара). Екеуін қосып тұрған сан, сондықтан
басты бетте бөлек те көрсетіледі:

| | Кітап | Юнит / бөлім | Сұрақ |
|---|---:|---:|---:|
| Оқулық (grammar + vocab) | 10 | 913 | 20 712 |
| IELTS | 3 | 24 | 960 |

Бөлу маңызды, өйткені IELTS-тің «юниті» — қырық сұрақтан тұратын тест бөлімі,
ал оқулықтың юниті — екі беттік тақырып. Қосылған 937 сан екі түрлі нәрсені
бір-біріне үйіп тұр. Басты беттегі жол `kind` бойынша бөледі (кітап тізімі
бойынша емес), әрі әрқайсысында қанша жауап бергенің де жазулы.

## Қалталар

```
site/              біріктірілген сайт — негізгі нұсқа осы (site/README.md)
site/tests/        тесттер: node site/tests/run.js (site/tests/README.md)
content/           ақылы кітаптардың JSON-ы. Репозиторийде де, деплойда да жоқ
                   (.gitignore); билдтен кейін upload_content.py Supabase-ке
                   итереді, оқушыға сол жерден барады
AUDIT.md           мазмұн дұрыстығы мен функционалдық аудиті

vocab-srs/         сөз карталарының түпнұсқа прототипі (React + Express).
                   Сайтқа кіретін нұсқасы — site/srs.js, серверсіз әрі
                   тәуелсіз; бұл қалта тарих үшін тұр, деплойға кірмейді
                   (node_modules .gitignore-да)

ayaulyayalama/     Essential Grammar in Use    ┐
enginuse/          English Grammar in Use      │ бастапқы жеке қосымшалар.
advancedinuse/     Advanced Grammar in Use     │ site/ солардың деректерінен
vocab-preint/      Vocabulary Pre-Intermediate │ жиналады, өздері өзгертілмейді
vocab-upint/       Vocabulary Upper-Int        │
vocab-adv/         Vocabulary Advanced         ┘
```

Бұл алтауынан `build_data.py`-ға керегі — тек `exercises.json`. Бесеуінде
оқулықтың PDF-і де жатқан, бірақ ол `site/pdf/`-тегімен байтпен бірдей
көшірме болатын, сондықтан алынып тасталды (билд PDF-ті әрқашан `site/pdf/`-тен
оқиды). Жалғыз ерекшелік — `ayaulyayalama/`-дағы 71 МБ түпнұсқа скан: ол
`site/pdf/essential-grammar.pdf`-тен (15.5 МБ) басқа әрі сапалырақ файл,
кейінге қалдырылған OCR жұмысына керек болғандықтан қалды.

Кейін қосылған төрт кітаптың бастапқы қалтасы жоқ — олар `site/pdf/`-тегі
PDF-тен тікелей оқылады:

```
site/tools/build_vocab_elem.py    → tools/vocab_elem_exercises.json
site/tools/build_collocations.py  → tools/collocations_exercises.json
site/tools/build_academic.py      → tools/academic_exercises.json
site/tools/build_business.py      → tools/business_exercises.json
site/tools/keyparse.py            соңғы үшеуіне ортақ кілт талдағышы
```

`build_data.py` сол төрт файлды оқып, қалған алтауымен бірге жинайды. PDF жолын
`BOOK_PDF` айнымалысымен ауыстыруға болады.

## Іске қосу

`fetch()` қолданылатындықтан файлды қос шертіп ашуға болмайды — сервер керек:

```
cd site && python3 -m http.server 8777
# http://localhost:8777
```

Деректерді бастапқы қалталардан қайта жинау:

```
python3 site/tools/build_data.py      # 10 grammar/vocabulary кітабы
python3 site/tools/build_ielts.py     # Cambridge IELTS 19/20/21
```

Екеуі де `data/index.json`-ды **біріктіріп** жаңартады (`tools/index_json.py`),
сондықтан біреуін жеке жүргізу қалғандарының жолдарын өшірмейді. Индекс
бұзылып қалса, дискідегі деректен қайта құруға болады:

```
python3 site/tools/index_json.py      # 13 кітап · 937 юнит · 21 672 сұрақ
```

Тексеру:

```
node site/tests/run.js
```

Серверді өзі көтереді, headless Chrome-ды қосады, бес жиынтықты жүргізеді
(деректің тұтастығы, жауап салыстырғышы, қосымшаның өзі, телефон мен офлайн,
админ бөлімі), сосын бәрін жабады. Толығырақ —
[site/tests/README.md](site/tests/README.md).

### Аудио (деплой)

Listening аудиосы (57 файл, ~340 МБ) репозиторийде жатыр және сайтпен бірге
деплойға кетеді, сондықтан **ештеңе баптаудың қажеті жоқ** —
`site/audio.config.js` ішіндегі `AUDIO_BASE` бос қалады, жолдар салыстырмалы
күйінде жұмыс істейді. GitHub Pages Range сұрауларын қолдайды (`206` +
`content-range`), яғни трек ішінде алға-артқа жылжу да істейді.

Есте ұстайтыны — көлем. PDF-термен қоса repo ~560 МБ; GitHub Pages жарияланған
сайт 1 ГБ-тан асқанда ескерте бастайды. Жаңа аудиосы бар кітап қосылса, сол
шекті қайта есептеу керек.

Бір кезде тарыла бастаса, `audio/` қалтасын объект-қоймаға (Cloudflare R2,
Backblaze B2, S3) сол күйі — `c19/`, `c20/`, `c21/` —
жүктеп, сілтемені `audio.config.js`-ке жазса жеткілікті:

```js
window.AUDIO_BASE = 'https://pub-xxxx.r2.dev/agylshyn-audio/';
```

Дерек файлдары бұл жағдайда да өзгермейді. Қоймадан талап етілетіні екеу: ашық
оқу (public read) және Range сұраныстары (`Accept-Ranges: bytes`). CORS керек
емес. Файл табылмаса, ойнатқыштың орнына «Аудио қолжетімсіз» деген жазу шығады
— үнсіз өлі батырма қалмайды.

## Тегін бөлігі және жазылым

Бес кітап толығымен тегін — `essential-grammar`, `grammar`, `vocab-elem`,
`vocab-preint`, `collocations`. Олар A1-ден B1-ге дейін жеткізеді, аккаунтсыз
да, интернетсіз де жұмыс істейді. Қалған сегізі (C1–C2 сөресі мен үш IELTS)
жазылыммен ашылады: **айлық 2000 ₸**, **мәңгілік 5000 ₸**.

Оқулық PDF-і мен Listening аудиосы — он үш кітаптың бәрінде ашық. Ақылысы —
жаттығулары: тексерілетін жауап, қателер беті, статистика, сессия.

```
site/data/<id>.json     тегін кітаптардың жаттығулары → офлайн кэштеледі
content/<id>.json       ақылы кітаптар (репозиторийден тыс, .gitignore-да)
Supabase book_content   оқушыға жететін жалғыз көшірме, RLS-пен қорғалған
site/pdf/<id>.pdf       оқулықтар — бәрі ашық
site/audio/…            Listening аудиосы — бәрі ашық
```

Құлыпты браузер емес, Postgres шешеді: `book_content` кестесінің select
саясаты `has_access()`-ке сүйенеді, ол `subscriptions` кестесіне қарап,
мерзімді сервердің сағатымен өлшейді. Ақылы кітаптың файлы сайтта мүлде жоқ,
сондықтан devtools-тағы кез келген өзгеріс құлыптың суретін ғана береді.

Төлем — Kaspi аударымы, ашу — `#/users` бетіндегі түйме. Толық баптау:
[site/README.md](site/README.md#ақылы-қабат-жазылым).

## Мүмкіндіктері

- Жауапты бірден тексеру, қателер беті, streak / mastered статистикасы
- **Жаттығу сессиясы** (`⚡`): бір экранда бір сұрақ — қателер, қайталау
  мерзімі жеткендер және жаңалары араласып келеді. Бір кітаптан не бәрінен
  бірдей; соңында нәтиже мен қате жауаптардың тізімі
- **Көмек (💡)**: жауаптың пішіні → бірінші әріптер → жауаптың өзі. Көмекпен
  берілген жауап меңгерілгенге жатпайды, сұрақ ертең қайта келеді
- **Тыңдау (🔊)**: сұрақты, дұрыс жауапты, сөздіктегі сөзді браузердің өз
  даусы оқиды (қосымша файл да, интернет те қажет емес)
- **Іздеу (Ctrl+K)**: сұрақтың мәтіні, жауабы, юнит атауы бойынша — бір
  кітаптан немесе бәрінен; нәтиже дәл сол сұраққа апарады
- Сөздік: сөзді меңзе (немесе қос шерт, ұзақ бас) — қазақша аудармасы шығады.
  1 385 сөздік ядро офлайн істейді, қалғаны API арқылы табылып кэштеледі
- **Сөз карталары (`🗂`)**: аудармасы шыққан терезедегі ＋ сол сөзді жеке
  жинағыңа қосады. Күн сайын аралық қайталау (SM-2): білсең — сирейді,
  ұмытсаң — жиілейді. Әр түйменің үстінде «келесі рет қашан» жазулы тұрады,
  сырғытып та бағалауға болады. Тізімнен (CSV/TSV) импорт, файлға сақтық
  көшірме — бәрі браузерде, серверсіз
- Оқулық PDF-і сол беттің ішінде, керекті бетінен ашылады
- Интерфейс екі тілде: қазақша / ағылшынша
- Тақырыбы екеу: ашық / қараңғы
- Прогресс уақыт белгісімен жазылады: «бүгін», күнделікті серия (streak),
  соңғы 30 күн графигі, бөлім бойынша әлсіз тұстар, қайталау кестесі
- Дәлдік пен қамту бөлек көрсетіледі; прогресті JSON-ға сақтап/қайтаруға болады
- **Аккаунт (қосымша)**: Google, поштаға келетін сілтеме немесе пароль арқылы
  кіресің де, прогресс бұлтқа сақталып, басқа құрылғыда жалғасады. Міндетті
  емес — баптау бос болса, түйме де көрінбейді, бәрі бұрынғыдай тек осы
  браузерде сақталады. Баптау: [site/README.md](site/README.md#аккаунт-және-бұлт-синхы-қосымша)
- **Қолданушылар тізімі (`#/users`)**: кім тіркелген, қашан кірген, қанша
  кітап пен жауап — сұрыпталатын кесте. Тек админге: админ болу деген
  `public.admins` кестесіндегі жол, ол кестеде жазу саясаты жоқ, сондықтан
  оны SQL Editor-ден ғана қосуға болады. Тізімнің өзін серверде `is_admin()`-ды
  қайта тексеретін функция қайтарады, яғни браузерде флагты «қосып қою» ештеңе
  бермейді. Тізімде санақ қана — басқа адамның жауаптары ешқашан ашылмайды
- Офлайн істейді (PWA — Service Worker кэштейді)

Толық құжаттама — [site/README.md](site/README.md).

### Шығарылым ақауларын жөндеу — `tools/repair.py`

Кітаптардың өз қатесі емес, PDF-тен шығарғанда пайда болған зақымдар билд
кезінде автоматты түзеледі. Әрқайсысының кепілдігі бір: түзетілген мәтін —
дәл сол әріптер, дәл сол ретте. Болжау жоқ, сондықтан үнсіз бұрмалау да жоқ.

| Ақау | Не істелді | Нәтиже |
|---|---|---|
| Бос орын белгілері жоғалған | Әр сұрақ PDF бетімен қайта туралады: бұл кітаптарда бос орын — сызылған ақ орын, яғни беттегі әдеттен тыс кең секіріс (қалыпты сөзаралық ≈5pt, бос орын 70–140pt) | 8 331 бос орын қалпына келді |
| Сөз ортасынан бөлініп кеткен (`cro ss`, `ne ws`) | Сол туралау PDF-тің өз жазылуын алып келеді; жауап кілттері кітаптың өз сөздігімен біріктіріледі | 220 → **11** |
| Цезарь ығысуы (қаріп картасы бүлінген) | Кез келген басқару таңбасы — бүліну белгісі (бұрын 3 ығысқан сөз талап етілетін, аралас жолдар өтіп кететін) | 27 → **0** |
| Бірігіп кеткен жауап кілттері | Екі бағанды жаттығуларды нөмірлері бойынша қайта құрастыру | 182 жол қалпына келді |
| Ұзын прозалық жауап автотексерілетін | `selfCheck` + себебі жазылған түсіндірме | 2 128 → **0** |
| Бір жаттығуда бір нөмір екі рет (жауаптары бір жазбаны бөлісетін) | Қайталанғанына жеке кілт (`k`: `1b`); көрінетін нөмір өзгермейді | 17 жол — енді екеуі де жеке саналады |
| Толтыру мүмкін емес жол (сұрағы «70 58 48», «___», бет нөмірі; жауабы да жоқ) | Алынып тасталды — юниттің жалпы санын босқа өсіріп тұрған | 30 → **0** |

Билд детерминді: қайта жүргізгенде нәтиже байтпен бірдей.

## Аудиттен кейінгі жөндеу

Аудитте табылған мәселелер бойынша жасалғаны ([AUDIT.md](AUDIT.md) §8 реті):

- **vocab-upint** енді нағыз Upper-Intermediate мазмұны (101 юнит, 2 626 сұрақ,
  өз PDF кілтімен 100 %). Бұрын Pre-Intermediate көшірмесі болатын.
- **essential-grammar**-дің 424 «елес» жолы (сұрағы да, жауабы да жоқ) алынды —
  статистика енді шынайы (1 984 нақты сұрақ).
- **grammar**-дің юнит атаулары мен бөлімдері PDF-тің Contents бетінен қайта
  оқылды (36 қате атау түзелді); grammar мен vocab-upint-ке `section` қосылды.
- **Жауап тексеру:** үтірлі тізімдер енді ретсіз салыстырылады
  (729 сұрақ 0 % → 100 %); беттің «Key to Exercises» іздері жауаптан кесілді.
- **Прогресс сенімді:** жауап бет жабылғанда бірден жазылады
  (`visibilitychange`/`pagehide`), екі қойынды бір-бірін өшірмейді
  (`storage` оқиғасында біріктіру), әр жазбада уақыт белгісі (`ts`) бар.
- **Статистика:** Дәлдік / Қамту / Меңгерілді / Бүгін карточкалары, 30 күндік
  график, бөлім бойынша жинақ, сұрыпталатын кесте, «қайталауға дайын» тізім.
- **Кітапаралық көрініс:** басты бетте жалпы дәлдік, «бүгін», «осы аптада»,
  барлық кітаптағы қате саны + 30 күндік график; әр кітап карточкасында
  қайталауды күтетін қате саны.
- **Қателер беті:** жауап жаңа әрекетке дейін жасырылады, ескі қате өріске
  толмайды («өткен жолы: …» болып бөлек), нұсқаулық әр жаттығуда бір рет.
- **Қолжетімділік:** кіріс өрістерінде `aria-label`, нәтижеде `aria-live`,
  кестеде пернетақта, белсенді таб/юнитте `aria-current`, модальда фокус қақпаны.
- **Мобиль:** табтар астыңғы жолаққа шықты — жоғарғы жолақ бір қатар, кітап
  атауы қиылмайды. Үш «Vocabulary in Use» деңгеймен ажыратылды.
- **Экспорт/импорт**, **офлайн (PWA)** қосылды.
- **Кейінге қалдырылды:** мәтіндегі OCR бос орындарын (`de grees`) автоматты
  жөндеу — сөздіксіз қауіпсіз істелмейді (дұрыс мәтінді бүлдіру қаупі);
  салыстыруға әсер етпейді. Авторлық құқық (Т6) — PDF-терді жариялау шешімі
  иесінде.
